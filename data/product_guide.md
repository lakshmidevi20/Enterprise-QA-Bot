# Acme Analytics Product Guide

## Data Import
Acme Analytics supports CSV, JSON, and XLSX file imports. A single uploaded file may be up to 250 MB.

## Data Export
Users with the Export permission can export report results as CSV or XLSX. Exported files are downloaded to the user's device; Acme Analytics does not automatically encrypt files after they are downloaded.

## Troubleshooting
Support personnel may request diagnostic logs when investigating product failures. Logs can include tenant identifiers, timestamps, request IDs, and error details.

## Roles
The built-in roles are Viewer, Analyst, and Administrator. Administrators can manage workspace membership and permissions.
